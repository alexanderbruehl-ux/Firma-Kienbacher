# Firma Kienbacher

Dieses Repository bündelt mehrere Einzelprojekte rund um Produktion und
Qualitätsmanagement bei Kienbacher.

## Projekte

- **[Überarbeitung QM-Dokumente](./Überarbeitung%20QM-Dokumente/)** –
  Revision der IATF-16949-Verfahrensanweisung 7V-5-1
  „Auftragsabwicklung in der Produktion" (Version k → l).
- **[Frage-Antwortkarten](./Frage-Antwortkarten/)** –
  Wenn-Dann-Regelkarten für Produktionsstörungen (Maschinen-, Werkzeug-,
  Personal- und Bedarfsprobleme) samt Workshop-Präsentation.

Jedes Projekt hat sein eigenes README mit Details zu Inhalt, Stand und
nächsten Schritten.
